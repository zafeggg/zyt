# 主网上线防复发检查清单（ZYT）

> 目的：把 testnet 阶段踩过的每个坑固化为可执行检查，确保主网部署与运营不再复发。
> 配套脚本：`zyt-contracts/scripts/mainnet-preflight.mjs`、`zyt-keeper/scripts/check-keeper-interfaces.mjs`、`zyt-keeper/scripts/rebuild-ledger-from-chain.mjs`
> 版本：v1.0（2026-09-26）

## 一、门禁脚本用法（每次部署前后各跑一次）

```bash
cd F:/zyt/zyt-contracts

# 部署前：源码修复特征 + 编译时效 + keeper 口径/配置 + 前端配置
node scripts/mainnet-preflight.mjs

# 部署后：追加「链上字节码 vs 本地编译产物」一致性校验（剥离 metadata 后比对）
node scripts/mainnet-preflight.mjs --addr deployments/<本次部署记录>.json

# keeper 接口一致性（静态 + 链上探针）
cd F:/zyt/zyt-keeper
node scripts/check-keeper-interfaces.mjs --probe
```

**判定**：脚本退出码 0 = 全部通过；1 = 存在 FAIL，必须处理后才继续。
**硬性要求**：`FAIL 0` 才允许进入下一步（部署 / 对外开放）。

## 三、上线流程门禁点

```
部署前 → [门禁 A] mainnet-preflight（FAIL 0）
      → 部署（deploy.js，确认网络/地址/参数）
      → 合约 verify（10/10）
部署后 → [门禁 B] mainnet-preflight --addr（字节码一致性）
      → keeper 部署 + check-keeper-interfaces --probe
      → 账本重建 + 对账全一致
      → 前端构建 + 上传 + 端点齐全验证
上线前24h → 小额真金全流程（入金/卖出/分红/推荐/记录页）
上线后 → 首次快照验证（次日 08:00 后查 /stats lastSnapshot）
      → 观察 48h 内对账、快照、监控告警
```
